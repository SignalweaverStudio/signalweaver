# LACUNA INTERFACE

Version 0.1  
Status: Early direction

## Current Development Interface

The current desktop dot is a production and validation tool.

It proves:

- acquisition is live
- the engine is updating
- the renderer receives q/p state
- the phase-space trajectory is coherent
- different interaction patterns produce different motion textures

It is not the finished interface.

## Intended Desktop Interface

The first finished product should be a screen overlay.

The overlay should:

- be movable
- be resizable
- occupy little screen space
- support transparency
- remain comfortable in peripheral vision
- avoid rectangular dashboard chrome
- present a window into the Liquid Lens
- preserve the Lacuna design language

Future desirable properties may include:

- always-on-top mode
- click-through mode
- subtle opacity control
- placement presets
- minimal start/stop controls
- context label and note entry
- accessible reduced-motion options

## Context and Notes

The interface may offer a user-selected context label such as:

- Working
- Reading / Research
- Watching / Listening
- Browsing / Social
- Gaming
- Away
- Other

The user may optionally add a note.

These labels and notes are testimony supplied by the user.

They are not automatically interpreted by Lacuna.

## Away State

Away may include an optional personal note, for example:

- Going for a walk
- Making coffee
- Phone call
- Needed a break
- Could not settle
- Lunch

When the user returns, Lacuna may show the note back to them.

It must not diagnose or score the reason.

## Future Embodiments

The interface layer should remain separable from the engine so that future embodiments may include:

- desktop overlay
- physical desk instrument
- studio display
- smart glasses
- wearable peripheral field
