# LIQUID LENS SPECIFICATION

Version 0.1  
Status: Working Draft

## Purpose

Liquid Lens is the primary visual technology through which the Lacuna field is expressed.

It is not a data visualisation.

It is not a graph.

It is not an animation responding directly to user input.

It is a physically believable optical medium whose behaviour arises entirely from the state of the Lacuna engine.

## Relationship to the Engine

The renderer never receives keyboard events.

The renderer never receives mouse events.

The renderer never receives application information.

The renderer receives only the current state of the Lacuna field.

Current field variables include:

- q
- p
- activity
- tempo
- irregularity
- idle

Future field variables may be added without altering the philosophy of the renderer.

## Design Principle

The renderer behaves as though a continuous reactive medium is suspended inside a precision optical cavity.

The medium possesses:

- cohesion
- viscosity
- inertia
- memory
- damping
- equilibrium

It should always appear to obey stable physical rules.

## Physical Model

The visual medium is inspired by:

- liquid lenses
- ferrofluid
- liquid crystals
- soap films
- optical gels
- suspended fluids
- thin-film optics

It is not intended to simulate any of these literally.

Instead it borrows their physical qualities.

## Material Properties

The medium should appear:

- deep
- glossy
- dense
- continuous
- heavy
- optically layered
- restrained

It should never appear:

- noisy
- explosive
- aggressive
- granular
- cellular
- spiky
- chaotic

## Optical Properties

The cavity should exhibit:

- subtle refraction
- optical depth
- internal reflections
- restrained thin-film colour
- anti-reflective edge behaviour
- smooth attenuation
- realistic shadowing

The optical effects should remain visible even during complete rest.

## Equilibrium

The medium possesses a natural resting state.

During equilibrium:

- motion approaches zero
- the field remains alive
- microscopic drift may exist
- optical depth remains visible

The resting state should feel peaceful rather than frozen.

## Disturbance

Changes in the Lacuna field disturb equilibrium.

Disturbance propagates through the medium.

Motion should appear continuous.

Nothing should teleport.

Nothing should instantly appear.

Every visible change should have a physical origin.

## Behaviour States

### Idle

Characteristics:

- near equilibrium
- mirror-like calm
- faint internal structure
- minimal movement
- suspended depth

### Low Activity

Characteristics:

- gentle folds
- broad standing waves
- soft optical distortion
- slow directional drift

### Sustained Activity

Characteristics:

- coherent ribbons
- flowing structures
- directional transport
- stable momentum

### Fragmented Activity

Characteristics:

- rounded droplets
- temporary separation
- orbital relationships
- eventual recombination

Fragmentation must remain elegant.

It must never resemble breaking.

### Recovery

As field energy decreases:

- folds soften
- droplets merge
- waves dissipate
- equilibrium gradually returns

Recovery should never snap instantly.

## Mapping Principles

The specification intentionally avoids prescribing exact equations.

Instead:

q should primarily influence displacement and large-scale structure.

p should primarily influence direction, momentum and flow.

Activity should primarily influence disturbance magnitude.

Tempo should influence temporal texture rather than raw speed.

Irregularity should introduce asymmetry while preserving coherence.

Idle should encourage smoothing, damping and return toward equilibrium.

Future implementations may refine these mappings while preserving the behavioural principles.

## Temporal Behaviour

The renderer should never depend directly upon frame rate.

Motion should remain stable across rendering frequencies.

Interpolation should preserve continuity.

The visual should never appear to strobe.

## Peripheral Comfort

Liquid Lens is intended to remain visible for many hours.

Therefore:

- avoid flashing
- avoid rapid oscillation
- avoid excessive contrast
- avoid unnecessary colour cycling
- avoid repetitive distracting motion

Comfort is a primary design objective.

## Explicitly Forbidden

The renderer must not produce:

- literal ferrofluid spikes
- cellular clustering
- trypophobia-triggering textures
- particle explosions
- electrical arcs
- lightning
- smoke simulations
- fire
- glowing neon effects
- HUD graphics
- game-like visual effects

## Desktop Overlay

The desktop overlay is a window into the Liquid Lens.

It is not a miniature dashboard.

The user should feel they are looking through a precision optical instrument rather than watching software.

## Future Embodiments

The same behavioural specification should support:

- desktop overlay
- physical desk instrument
- studio edition
- wearable optics
- smart glasses

Only the embodiment changes.

The field behaviour remains recognisably Liquid Lens.

## Rendering Philosophy

The renderer exists to reveal the Lacuna field.

It does not decorate it.

It does not dramatise it.

It gives physical presence to something that would otherwise remain invisible.

The highest compliment a user can give is not:

"That animation is beautiful."

It is:

"I forgot I was looking at software."
