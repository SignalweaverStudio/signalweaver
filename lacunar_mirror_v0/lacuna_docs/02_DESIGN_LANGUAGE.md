# LACUNA DESIGN LANGUAGE

Version 0.1  
Status: Working doctrine

## Core Identity

Lacuna should feel like a precision scientific instrument.

It should evoke:

- optical engineering
- scientific metrology
- microscopy
- astronomy
- horology
- precision machining
- museum-quality laboratory objects
- timeless scientific hardware

It should avoid:

- dashboards
- HUDs
- gaming interfaces
- cyberpunk
- RGB aesthetics
- holograms
- productivity visualisers
- emotional avatars
- decorative noise

## Current Hero Direction

The leading physical identity is:

**The Concave Well**

A shallow, dense optical instrument composed of:

- dark gunmetal stainless steel
- raw naval brass tension ring
- microscopic fasteners
- concave sapphire crystal
- subtle anti-reflective edge coatings
- a dark optical cavity
- index-matched reactive fluid
- a dense tungsten core

The object should feel:

- calm
- heavy
- expensive
- believable
- precise
- maintainable
- timeless

## Liquid Lens Behaviour

The Liquid Lens is not a bowl containing loose fluid.

It is an optical field suspended within a thin cavity.

The medium may condense into:

- smooth ribbons
- broad folds
- low-frequency standing waves
- continuous directional flow
- smooth rounded droplets
- gentle planetary separations
- soft optical distortions

The medium should always remain cohesive.

## Behaviour States

### Idle

- calm equilibrium
- mirror-smooth or near-smooth surface
- faint depth
- minimal internal movement
- alive, not animated

### Typing

- low-frequency standing waves
- smooth concentric or offset rings
- heavy rather than sharp
- no spikes
- no clustered points

### Mouse Stroke

- directional flow
- elongated smooth ribbon
- movement follows field momentum
- broad, coherent deformation

### Fragmented Activity

- several rounded droplets or separated masses
- slow orbital relationship
- no chaotic clustering
- no cellular breakup
- eventual recombination

### Returning to Idle

- energy dissipates
- folds soften
- droplets merge
- optical surface rebalances
- no abrupt snap

## Desktop Overlay

The desktop overlay is not a miniature physical product.

It is a window into the Liquid Lens.

The overlay should inherit the values of the physical instrument even when the metal housing is not visible.

The overlay should feel:

- optically precise
- calm
- deep
- restrained
- physically grounded
- peripheral

It should not feel like a software panel.

Possible future embodiments:

- Lacuna Lens

Liquid Lens is the visual technology.

Lacuna is the instrument.
