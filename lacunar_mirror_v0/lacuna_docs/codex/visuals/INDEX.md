# LACUNA VISUAL CODEX

This folder preserves visual exploration for the Lacuna design language.

## Leading Direction

**Concave Well / Liquid Lens Instrument**

Core constraints:

- calm scientific instrument
- concave sapphire optical cavity
- gunmetal and restrained naval brass
- smooth cohesive reactive medium
- no spikes
- no cellular or clustered textures
- no trypophobia-triggering patterns
- visualises the Lacuna field, not raw actions or inferred mental states
