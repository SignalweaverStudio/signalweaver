# LACUNA CODEX

The Codex is Lacuna's evolving design and research journal.

The Constitution defines what Lacuna is.

The Codex records how Lacuna is evolving.

Use the Codex for:

- visual concepts
- prompts
- external AI reviews
- rejected ideas
- screenshots
- research observations
- design decisions
- open questions
- experimental results

Suggested folders:

- visuals
- research
- decisions

The Codex may change freely.

The Constitution should change rarely and deliberately.
